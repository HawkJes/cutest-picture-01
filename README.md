A baby fawn with enormous sparkling dark eyes and long lashes, a tiny pink nose, and one pale-blue butterfly resting on its nose — the cutest picture I could make. One subject, one charm touch, warm cream background, nothing else competing for the eye. The program copies the vendored `entry.png` to the output path, byte for byte, every run, and verifies it with a sha256 self-check.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py
```
